隐私政策

Lychee-Chat 是一个运行在 Chrome 中的浏览器扩展，让你与支持视觉能力的 AI 模型讨论当前页面，并在每一轮对话中按需附带页面截图。

生效日期：2026-10-24 适用产品：Lychee-Chat Chrome 扩展 版本：0.2.0

1. 概述

本政策说明 Lychee-Chat 如何处理你的配置、对话内容和页面截图。Lychee-Chat 采用“自带密钥”（BYOK）模式：你自行选择 AI 模型提供商并输入 API Key，扩展直接把请求发送到该提供商的 API。

开发者不运营中转服务器。 Lychee-Chat 不收集、不接收、不存储你的 API Key、聊天内容或截图。数据直接在你的浏览器与所选提供商之间传输。

2. 扩展访问哪些数据

  • 当前页面截图：仅在你通过工具栏图标打开聊天窗，并发送消息且开启截图时捕获。扩展不会持续录屏，也不会在后台定时截图。
  • 图片附件：你主动点击附件按钮选择并随消息发送的图片，最多 4 张。
  • 当前页面内容：截图由 Chrome 的可见标签页捕获能力生成，扩展不读取完整浏览历史。
  • 聊天内容：你输入的文本和所选模型返回的文本。
  • 配置信息：所选提供商、Base URL、模型、API Key，以及本地保存的会话记录。

3. 数据存储在哪里

API Key、模型配置和聊天文本通过 chrome.storage.local 保存在你的本地 Chrome 配置中；界面偏好（主题、聊天窗位置、是否显示页面悬浮按钮）也仅保存在本机。它们不会同步到开发者服务器，也不会上传到 Lychee-Chat 自建的服务。

页面截图和你上传的图片只在发送请求时短暂保留在内存中，并发送给你选择的模型提供商；Lychee-Chat 不会把图片内容持久化到本地存储。重新打开页面后，历史消息中的图片只显示占位提示和文件名。

你可以在聊天窗中删除单个会话，或通过移除扩展来清除扩展保存在本地的数据。提供商一侧的数据保留规则由该提供商决定。

4. 数据发送给谁

当你发送消息时，Lychee-Chat 会把该轮对话文本、按需附带的页面截图、你主动上传的图片附件和必要的请求参数发送到你选择的提供商 API。你的 API Key 作为身份凭证随请求发送给该提供商。

预置提供商可能包括：月之暗面、DeepSeek、阿里云百炼、智谱、豆包/火山方舟、MiniMax、小米 MiMo、硅基流动、Anthropic、OpenAI、Google Gemini、xAI、OpenRouter，以及本地运行的 Ollama 或 LM Studio。自定义提供商的地址由你填写。

这些第三方服务会按照各自的隐私政策和服务条款处理数据。使用前请阅读对应提供商的条款。Lychee-Chat 不控制第三方的处理方式。

内置的“Lychee Demo”演示模式不会请求任何外部接口，只返回本地预设的演示回复。

5. 我们不做什么

  • 不向开发者服务器上传 API Key、聊天内容或截图。
  • 不把数据出售、出租或用于广告定向。
  • 不把用户数据用于训练 Lychee-Chat 或任何模型。
  • 不包含分析 SDK、广告 SDK 或远程代码；扩展运行的所有代码都打包在安装包内。
  • 不读取与当前对话无关的浏览历史或后台标签页内容。

6. 权限说明

  • activeTab：在你点击扩展图标后，允许扩展访问当前标签页并捕获当前可见页面的截图。
  • scripting：用于在当前页面注入右上角的浮动聊天窗。
  • storage：保存模型配置、API Key 和本地会话记录。
  • 特定 API 域名权限：用于连接你选择的 AI 提供商接口。
  • 可选域名权限：当你添加自定义提供商时，扩展会在保存或测试时请求该接口域名的访问权限。

7. 儿童隐私

Lychee-Chat 不是面向 13 岁以下儿童设计或提供的产品。请勿让儿童使用本扩展发送个人信息或包含个人信息的页面截图。

8. 有限使用承诺

Lychee-Chat 对用户数据的访问、使用和传输仅用于提供其单一用途：让用户与视觉模型讨论当前页面。我们不会将数据用于与这一用途无关的目的，也不会出售用户数据。

9. 政策更新

如果本政策发生实质性变化，我们会更新本页面的生效日期和版本说明。继续使用扩展即表示你接受更新后的政策。
